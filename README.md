# 주차장 찾기

내 위치나 가게 이름을 넣으면 주변 주차장과 **지금 빈자리**를 보여주고, 주차한 시각을 넣으면 **요금을 실시간으로 계산**해 줍니다.

## 만든 기능

1. **주변 주차장 찾기** — 현 위치 기준 100m / 500m / 1km / 3km 안의 주차장을 간이 지도와 목록에 표시 (지정 위치 검색은 다음에)
2. **주차장 정보** — 빈자리(실시간), 요금(기본·추가·일 최대), 규모(총 주차면수), 운영시간, 유료/무료, 야간 개방
3. **요금 계산기** — 주차장과 주차한 시각을 넣으면 지금까지 쌓인 요금을 1분마다 다시 계산

## 바로 열어보기

```bash
node server.mjs
```

→ http://localhost:3000

## 쓰는 자료

| 자료 | 쓰는 곳 |
|---|---|
| 서울시 열린데이터광장 · 공영주차장 안내 정보 (`GetParkInfo`) | 주차장 위치·요금·규모·운영시간 (2,190곳, 좌표 1,456곳) |
| 서울시 열린데이터광장 · 시영주차장 실시간 정보 (`GetParkingInfo`) | 실시간 빈자리 (122곳) |
| 한국교통안전공단 주차정보 (`PrkRealtimeInfo_v1`) | 실시간 빈자리 보강 |


## 인증키

인증키는 **`.env` 에만** 둡니다. `.env` 는 `.gitignore` 로 막혀 있어 깃허브에 올라가지 않습니다.

`.env.example` 을 복사해 `.env` 로 만들고 값을 채우세요.

```
SEOUL_API_KEY=     # 서울시 열린데이터광장
KOTSA_API_KEY=     # 공공데이터포털 (한국교통안전공단 주차정보)
```

배포할 때는 같은 이름으로 환경변수를 넣으면 됩니다.

### 깃허브 Secrets 넣는 법

저장소 → **Settings → Secrets and variables → Actions → New repository secret** 에서 2개를 넣으세요.

| 이름 | 값 |
|---|---|
| `SEOUL_API_KEY` | 서울시 열린데이터광장 인증키 |
| `KOTSA_API_KEY` | 공공데이터포털 일반 인증키(Decoding) |

이름을 `PARK_1` / `PARK_2` 로 넣어도 됩니다. 어느 쪽이 어느 키든 **길이로 알아서 구분**합니다
(서울시 인증키는 30자 안팎, 공공데이터포털 인증키는 64자).

넣으면 `.github/workflows/update-realtime.yml` 이 **10분마다** 실시간 빈자리를 받아
`data/realtime.json` 으로 저장소에 올립니다. 사이트는 그 파일만 읽으므로 **인증키가 화면에 노출되지 않습니다.**

바로 한 번 돌려보려면 저장소 **Actions → 실시간 빈자리 갱신 → Run workflow**.

### GitHub Pages 켜기

**Settings → Pages → Source: Deploy from a branch → main / (root) → Save**

## 데이터 다시 받기

주차장 위치·요금 같은 정적 정보를 최신으로 바꾸려면:

```bash
node scripts/build-data.mjs
```

## 알아두기

- 요금은 공개된 기본·추가 요금으로 계산한 **참고값**입니다. 실제 정산 금액과 다를 수 있습니다.
- 실시간 빈자리는 20분 안쪽 연계 데이터가 있는 주차장만 표시합니다. 나머지는 빈자리 표시 없이 나옵니다.
- 서울시 API가 좌표를 주는 곳은 117곳(시영주차장)이라 그만큼만 지도에 뜹니다.
- 실시간 빈자리는 깃허브 Actions 주기 때문에 최대 10~15분 늦을 수 있습니다.
