# 주차장 찾기

내 위치나 가게 이름을 넣으면 주변 주차장과 **지금 빈자리**를 보여주고, 주차한 시각을 넣으면 **요금을 실시간으로 계산**해 줍니다.

## 만든 기능

1. **주변 주차장 찾기** — 현 위치 또는 지정 위치(가게·식당 이름도 가능) 기준으로 100m / 300m / 500m / 1km 안의 주차장을 지도와 목록에 표시
2. **주차장 정보** — 빈자리(실시간), 요금(기본·추가·일 최대), 규모(총 주차면수), 운영시간, 유료/무료, 야간 개방
3. **요금 계산기** — 주차장과 주차한 시각을 넣으면 지금까지 쌓인 요금을 1분마다 다시 계산

## 바로 열어보기

```bash
node server.mjs
```

→ http://localhost:3000

## 쓰는 자료

| 자료 | 쓰는 곳 |
|---|---|
| 서울시 열린데이터광장 · 공영주차장 안내 정보 (`GetParkInfo`) | 주차장 위치·요금·규모·운영시간 (2,190곳, 좌표 1,456곳) |
| 서울시 열린데이터광장 · 시영주차장 실시간 정보 (`GetParkingInfo`) | 실시간 빈자리 (122곳) |
| 한국교통안전공단 주차정보 (`PrkRealtimeInfo_v1`) | 실시간 빈자리 보강 |
| 카카오 로컬 API (선택) | 가게·식당 이름 → 좌표, 지도 표시 |

## 인증키

인증키는 **`.env` 에만** 둡니다. `.env` 는 `.gitignore` 로 막혀 있어 깃허브에 올라가지 않습니다.

`.env.example` 을 복사해 `.env` 로 만들고 값을 채우세요.

```
SEOUL_API_KEY=     # 서울시 열린데이터광장
KOTSA_API_KEY=     # 공공데이터포털 (한국교통안전공단 주차정보)
KAKAO_REST_KEY=    # 선택 - 없으면 가게 검색 대신 주차장 이름 검색으로 동작
KAKAO_JS_KEY=      # 선택 - 없으면 간이 지도(SVG)로 동작
```

배포할 때는 같은 이름으로 환경변수를 넣으면 됩니다.

### 카카오 키 받는 법 (3분, 안 받아도 사이트는 돌아갑니다)

1. [developers.kakao.com](https://developers.kakao.com) 에 카카오 계정으로 로그인
2. **내 애플리케이션 → 애플리케이션 추가하기** (앱 이름·회사명 아무거나)
3. **앱 키** 화면에서 `JavaScript 키` → `KAKAO_JS_KEY`, `REST API 키` → `KAKAO_REST_KEY` 에 복사
4. **플랫폼 → Web 플랫폼 등록** 에 `http://localhost:3000` 과 배포 주소를 넣기
5. **카카오 맵 → 활성화 ON**

## 데이터 다시 받기

주차장 위치·요금 같은 정적 정보를 최신으로 바꾸려면:

```bash
node scripts/build-data.mjs
```

## 알아두기

- 요금은 공개된 기본·추가 요금으로 계산한 **참고값**입니다. 실제 정산 금액과 다를 수 있습니다.
- 실시간 빈자리는 20분 안쪽 연계 데이터가 있는 주차장만 표시합니다. 나머지는 빈자리 표시 없이 나옵니다.
- 좌표가 없는 주차장 734곳은 지도에 찍을 수 없어 목록에서 제외됩니다.
